# Al-QURANITE 🕋

**Al-QURANITE** is an Islamic knowledge platform designed to provide authentic, accessible, and inspiring resources. It features a public-facing website for reading Quran, Hadith, and articles, alongside a secure admin dashboard for content management.

## ✨ Features

- **Public Website**: Responsive design with sections for Quran, Hadith, Belief, Worship, and Education.
- **Dynamic Article System**: Articles are stored in Supabase with hybrid loading (Database + Static backup).
- **Admin Dashboard**: Secure login to manage articles (CRUD), reply to user messages via email, and view analytics.
- **Email Notifications**: Admins can reply to contact form submissions, and users receive beautifully formatted HTML emails.
- **Responsive UI**: Optimized for mobile, tablet, and desktop using Bootstrap 5.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES Modules), Bootstrap 5, Chart.js
- **Backend**: Supabase (PostgreSQL, Auth, Storage, Edge Functions)
- **Email Service**: Gmail SMTP (via Deno Edge Functions)
- **Hosting**: GitHub Pages (Static Frontend)
